# Browser demo

Open the **live demo** link in this repository's README. The sample opens with its computed report, chart and evidence table. Choose **Input JSON** to edit the example or open a JSON file of your own. **Run analysis** executes the project's Python code on your device. **Export report** downloads the current result as JSON.

Use semantic search to find rows related to a question in English. The first search downloads about 46 MB of model and runtime files. A quantized MiniLM encoder compares your search with up to 16 evidence rows and links each result to its source row. Similarity scores measure how closely the text matches your query.

The bundled example includes a short question generated by a local Gemma model. Fresh generative commentary from a local model, Azure OpenAI, Amazon Bedrock or an API is available in the full application. See [model settings](../README.md#connect-a-model).

The demo serves software and model files from its own GitHub Pages origin. Your imported data and search text are processed in the browser.

## Build from source

From the repository root with Python 3.11 or newer:

```sh
python demo/build_demo.py --out public
python demo/fetch_runtime.py public/python
python -m http.server 8000 --directory public --bind 127.0.0.1
```

Open <http://127.0.0.1:8000>. The first build requires internet access to fetch files listed in [the SHA-256 lockfile](assets.lock.json). On a fork, set the repository's Pages publishing source to GitHub Actions for automatic deployments.

The browser engine uses [Pyodide](https://github.com/pyodide/pyodide). Semantic search uses [Transformers.js](https://github.com/huggingface/transformers.js), [ONNX Runtime](https://onnxruntime.ai/) and the [quantized MiniLM model](https://huggingface.co/Xenova/all-MiniLM-L6-v2). The build includes upstream licenses and the model card under `licenses/`.
